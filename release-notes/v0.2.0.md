# Tether 0.2.0

Released 2026-10-23

## Highlights

- **Windows servers.** Connect to Windows 10/11 and Windows Server hosts running OpenSSH: PowerShell terminals, the file manager, transfers, and the host panel (system, processes, services, network, ports, event logs, GPUs and containers).
- **Touch ID for saved passwords.** Save SSH passwords and key passphrases in the macOS keychain once; afterwards Touch ID (or your Mac's password) signs you in. Completely optional.
- **sudo, su and other prompts in terminals.** When a terminal asks for a password, a bar offers to fill a saved one with Touch ID (⌥⌘P) or to type one in a secure field and save it.
- **Many files travel as one stream**: packed with `tar` on your Mac and unpacked on the server (and the other way round), much faster for folders full of small files.

## New

- **Windows hosts** (OpenSSH, cmd or PowerShell as the default shell). Tether detects the shell on first contact with one short command and remembers it. Nothing is installed on the server.
  - Terminals run PowerShell, with "Open Terminal Here" support.
  - Host panel: OS version and build, CPU, memory, page file, disks, network adapters, processes (with end/kill), Windows services (start, stop, restart, logs), listening ports with their processes, established connections, System/Security/Application event logs, NVIDIA GPUs, Docker/Podman containers.
  - File manager with drives, upload/download, rename, move, copy, delete, new folder and `.tar.gz` (Windows' built-in tar). The SSH key wizard installs keys for normal and administrator accounts.
  - Limits: Windows has no tmux or screen, so a shell ends when the connection drops (output stays in the recording); file permissions cannot be changed; transfers are copied file by file.
- **Keychain + Touch ID** (Settings ▸ Passwords):
  - "Remember in Keychain" when signing in, for passwords (every jump host too) and SSH key passphrases.
  - Ask for Touch ID before a saved password is used, then not again for a chosen time (every time … 1 hour). Locking the screen or sleeping always asks again.
  - All saved items in one list, with their kind (login, sudo, key passphrase), each removable.
- **Password prompts inside terminals.** Recognizes `[sudo] password for …:`, `Password:` (su, login), `user@host's password:` (ssh from the server), key passphrases and similar prompts. Fill a saved password with ⌥⌘P or the bar's button (Touch ID first), or choose "Enter…" to type one securely and optionally save it for that prompt. Nothing is typed without your click; "new password" prompts are ignored.
- **Packed transfers.** Uploads and downloads with many files are sent as a single tar stream through the existing SSH connection. Files are unpacked into a hidden staging folder and then moved into place, so a cancelled or failed transfer leaves nothing half-copied and never overwrites anything.
- **Parallel transfers.** Items that are not packed are copied with scp several at a time (3 by default), in the order they were added.
- **Settings ▸ Transfers:** when to pack (*when there are many files*, *always*, *never*), the file-count threshold, compression on the wire, and how many transfers run at once. The upload sheet shows the number of files and total size and lets you choose *As one stream* or *File by file* for that upload.
- **Update notice.** At launch Tether asks GitHub once whether a newer release exists and, if so, says so with a link to the release page (also an "Update" badge next to the version in the sidebar). Nothing is downloaded; offline, nothing happens. Can be turned off in Settings ▸ General.
- **`make` targets** for building, testing, installing, packaging and a demo with synthetic data (`make help`).
- Screenshots in the README.

## Improved

- **Transfers panel** shows what went where: source → destination for every transfer, the full list of items in a packed transfer (renamed ones marked), bytes moved, speed, ETA and a summary when finished. It sizes itself to its content (up to a maximum height), and removing entries animates cleanly. **Copy Path** confirms with a visible "Copied".
- **Downloads never overwrite local files**: a name that already exists gets a Finder-style suffix (`report 2.pdf`).
- Install, first-launch and uninstall instructions in the README.

## Fixed

- Port numbers and process IDs were shown with thousands separators in some languages (e.g. "3.000" instead of 3000).
- Downloading to Downloads could replace an existing file with the same name.
- Cancelling a queued transfer now reports the transfer as finished, so the pending upload indicator over the terminal clears.
- The host editor no longer fills the password field with the saved password (which bypassed the keychain check); type a new one to replace it.

## Notes

- The sidebar's search button was removed; search stays in the toolbar (⇧⌘F).
- Packed transfers need `tar` on the server, which practically every Unix system has (GNU tar and BusyBox tar were tested). Choose *Never* in Settings ▸ Transfers to always copy file by file.
- Windows support is new and has not been tested against every Windows version. Please report what does not work.
