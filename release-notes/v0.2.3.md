# Tether 0.2.3

Released 2026-10-23

## Highlights

- The file manager is easier to move around in, even on a small screen: large Back, Forward, Up and Home buttons, a clickable path, bigger rows, and an Owner column.
- ⌘↩ opens New Connection with the host search ready for typing, for connecting without the mouse.
- Server identity checks: a changed host key gets a clear warning with the new fingerprint and a guarded way to accept it; new servers show their fingerprint to compare.

## New

- ⌘↩ opens New Connection on the saved-hosts search, with the search field focused.
- New Connection lists This Mac with the saved hosts, so a local terminal opens from the same search.
- File manager: Forward history (⌘] or the mouse's forward button) next to Back (⌘[ or the mouse's back button).
- File manager: the current path is shown as clickable folders; click one to go there.
- File manager: an Owner column (owner:group) beside Permissions.
- The terminal's status bar has a Browse button that opens a file manager in the terminal's current directory.
- The tab bar shows arrows and a scroll bar when there are more tabs than fit.

## Improved

- A server whose host key changed: the connection card explains what it can mean, shows the new key's fingerprint, and offers Remove Old Key… (with confirmation; known_hosts keeps a .old copy). Tether then asks you to verify the new key as on a first connection. Sessions that were online before stop retrying instead of looping.
- First connection to a server: the Verify Host question shows the key fingerprint on its own line, and you can paste the fingerprint you were given to compare. A mismatch blocks Trust and Continue, and the button arms a second after the question appears so a stray Return cannot accept a key.
- The host panel shows known ssh failures (like a changed host key) as one sentence; ssh's full output is one click away.
- File manager: larger toolbar buttons and file icons, and taller rows.
- File manager: on a narrow window the details move below the list (shown for the selection), so the list keeps its width. Owner and Permissions columns appear when the list is wide enough; otherwise both are shown in the details.
- ⌘T in a file manager opens another file manager in the same folder instead of a terminal.
- Local terminals start in the home folder, not in "/".
- New file manager tabs open in the home folder unless a folder is given.
- Many terminals to one host: a connection busy with other tabs' output is no longer mistaken for a dead one, and the app can open more files at once, so opening dozens of tabs quickly no longer drops sessions.

## Fixed

- New Connection: typing part of a saved host's name selects that host; the direct connection to what was typed is offered below the saved hosts instead of above them.
- The terminal's status bar stays on one line in narrow windows.
- The read-only history view (archive and recordings) scrolls with the mouse wheel and the scroll bar.
