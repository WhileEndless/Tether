# Tether 0.2.1

Released 2026-10-23

## Fixed

- **Ctrl+L and `clear` no longer erase history.** Like Terminal.app, the lines on the screen are moved into the scrollback first; the prompt still goes to the top. The remote side can no longer wipe the scrollback (`ESC[3J`, sent by `clear`). ⌘K (Clear Scrollback) still clears everything.
