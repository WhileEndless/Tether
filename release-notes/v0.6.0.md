# Tether 0.6.0

Released 2026-10-26

## Highlights

- Find in the terminal shows where you are: "3 of 14" in the find bar, the line of the current match highlighted across the terminal, the match itself in a solid box that bounces and blinks when you reach it, and marks beside the scroller for every match in the history.
- Secrets in the archive are masked: when a session ends, API keys, tokens, private keys and passwords in its recording are replaced with `[REDACTED****]`. The list of patterns can be extended.

## New

- ⌘F opens Tether's own find bar in terminals: type to search, ↩ / ⇧↩ (or ⌘G / ⇧⌘G) for the next and previous match, options for case, whole words and regular expressions, and a track showing how far through the matches you are.
- Settings ▸ Terminal ▸ Find in Terminal: line and match colors, tinting of the other matches, scroller marks, what happens when a match is reached (bounce, blink, both or nothing; nothing moves with Reduce Motion), and how long typing must pause before the terminal is searched (300 ms by default, so long histories are not searched for every letter; ↩ searches at once).
- Settings ▸ Security ▸ Secrets in the Archive: built-in patterns (AWS, GitHub, GitLab, OpenAI, Anthropic, Google, Slack, Stripe, npm, Hugging Face, JWTs, bearer tokens, passwords in URLs, `*_KEY=` / `*_TOKEN=` / `*_PASSWORD=` values, private key blocks), each can be switched off; add your own rules, try them on a sample line, and apply the rules to the whole archive again.
- Settings ▸ Terminal ▸ Floating Bars: the find bar closes by itself after a while unused (20 seconds by default, or never), and how long finished or failed uploads stay on screen.

## Improved

- The search window says it is searching while it looks (with how many sources it has gone through and how many matches so far) and shows "No Matches" only once the search has finished; a stopped search says so.
- Opening a match from the search window starts the terminal's find bar on that match.
- `make privacy` also looks for API keys and tokens, and `make hooks` runs it before every commit.

## Notes

- Masking applies to recordings of archived sessions, including those archived before this version (done once in the background after launch). Open sessions are never changed. Secrets keep their length, so recordings, transcripts and search work as before. Masking is a safety net: secrets in unusual formats, split by colors or line breaks, or kept elsewhere (the server's shell history) are not caught.
