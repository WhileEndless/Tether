# Tether 0.10.4

Released 2026-11-07

## Highlights

- Codex copies now reach the Mac clipboard reliably from tmux-backed remote tabs.

## Improved

- Codex tabs use a distinct mark and report active work from foreground activity when the agent does not provide a more specific state.

## Fixed

- A software-update window could rarely draw parts of its text upside down on older macOS 26 releases. It now redraws after the window's layer tree has settled.
- Codex clipboard copies now work through both tmux clipboard delivery paths: its native control-client path and OSC 52 passthrough. Large supported OSC 52 payloads are retained across transport chunks.
- A tab with no explicit agent wait reason no longer claims that it is waiting.
