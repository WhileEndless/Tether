# Tether 0.8.1

Released 2026-10-26

## Highlights

- Re-attaching over a slow connection is dependable: tmux sessions are no longer reported as ended or closed while they are still running on the server.

## Fixed

- A slow server or connection no longer makes a reconnecting tab look like a plain shell, which showed tmux's control text in the terminal and could end with "Shell exited" or "The remote session no longer exists" although the session was still there.
- When tmux drops the connection for another reason than a detach (for example a client that fell too far behind on a slow link), Tether checks the server and re-attaches instead of reporting "Session ended".
- Output printed while you were away is fetched in steps (1,000 lines, then 10,000, then everything the server kept) instead of the whole history at once, and the restore shows how much has arrived.
