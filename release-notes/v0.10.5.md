# Tether 0.10.5

Released 2026-11-08

## Highlights

- Coding-agent tabs now make Codex's live output visibly distinct from an open but quiet terminal, without reading terminal text or making extra server requests.

## New

- Tether recognises Cursor Agent, Gemini CLI and Aider alongside Claude Code, Codex and opencode in tmux sessions.
- Settings has a search field that opens the matching settings category.

## Improved

- Codex has a clearer original tab mark and a lightweight activity ring while it works.
- Coding-agent notification and refresh controls now live in Settings ▸ Monitoring.
- The remote-command reference documents exactly which coding-agent session information may be read and confirms that no terminal transcript is collected.

## Fixed

- Codex work is detected directly from new terminal output even when optional command CPU and I/O sampling is disabled.
- Agent state no longer presents an unreported state as idle.
- Downloaded release archives no longer include macOS metadata sidecars that invalidate the app signature after extraction.

## Notes

- Claude Code can provide structured waiting and working states. Other interactive CLIs show working while they produce terminal output, then remain active while their state is unknown.
