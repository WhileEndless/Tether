# Tether 0.10.7

Released 2026-11-17

## Highlights

- More reliable work across multiple displays, with responsive terminals while busy commands stream output.

## Improved

- Release archives omit local filesystem ownership metadata and compiler debug records.
- Terminal output shares a bounded processing budget so background tabs leave time for typing and window interaction.
- Heavy output can overflow to an encrypted temporary buffer instead of growing memory without a limit. Output remains ordered and is delivered before the process's exit is shown.

## Fixed

- Command monitoring no longer spins on the main thread when windows become hidden, including during display changes.
- Cancelled monitoring tasks cannot interfere with a newly started watcher after sleep or reconnecting.
- Rapid window-size changes apply the latest bounds without waiting for a busy terminal to stop printing.
- Moving between Retina and other displays preserves terminal modes, history reading positions and text selections.
- Windows restored from another display layout fit the available screens and keep their title bars reachable.

## Notes

- Saved hosts, sessions, settings and recordings keep their existing formats.
- Temporary output buffers use per-session encryption with keys held only in memory; consumed files are removed.
- The release download contains the application and its runtime resources, without local hosts, session data, recordings or diagnostic logs.
