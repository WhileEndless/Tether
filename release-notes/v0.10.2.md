# Tether 0.10.2

Released 2026-11-03

## Highlights

- Port forwarding is much simpler: say what you want in plain words, and Tether picks a free port, says what will happen and starts it at once.

## New

- Forward a Port… offers four plain choices: open a port of the server on this Mac, reach another machine through the server, let the server reach this Mac (or a machine on its network), or browse through the server with a SOCKS proxy.

## Improved

- The port on this Mac follows the port you want to reach (the same number when it is free, the next free one otherwise; ports below 1024 open as 8000 and up), and the editor says in one sentence what the forward will do, with the server's name and the real ports. A port already in use offers a free one.
- Adding a forward starts it right away (*Add and Start*); saving a running forward makes it again with the new values.
- Each forward says whether it is on, off, waiting for its server or failed, and what that means ("Off — nothing listens on port 8090 of this Mac"). A failed one offers *Try Again*, and a free port when its own is taken.
- Updates are never installed without asking: a downloaded update waits until you choose *Restart to Update* and confirm. Quitting Tether no longer installs it, and the setting is now called *Download updates in the background*.
- "Other devices on my network can use it" replaces typing a bind address (custom addresses stay under Advanced).
- Ports the server listens on show the forward already made for them, with its address and a browser button, or *Turn On* when it is off. With monitoring off, the panel says how to forward a port by number.

## Fixed

- The scroller no longer shrinks with every key while a program such as Claude Code draws on the normal screen, and scrolling up there no longer shows the same screen with *Back to Live*.
- A tab reopened after a relaunch no longer takes such redraws for older output: scrolling to the top stays in the terminal when it already holds everything.
- The Ports tab no longer appears for this Mac, where forwarding does not apply.
- ⇧⌘G back through matches in a session's recording reads the part that holds the match once, from where the search found it: in a long coding-agent session a step took about ten seconds and now takes about two.
- The tab bar's arrows show only when there are more tabs that way: at the first or last tab its arrow is hidden (its place kept, so the tabs do not move), also after scrolling with the arrows.
- Re-attaching to a tmux session fetches only what was printed while away: Tether keeps track of how far the server's history had grown and asks for about that much first (further back only when the place is not in it). Rows a program redrew in place (Claude Code's prompt box and status line, with the conversation above them unchanged) no longer count as lost: the output above them is enough to find the place, and new messages that took the old box's place are added. Before, Tether then looked back through 1,000, then 10,000 rows, then the whole history (up to 100,000), and printed the last 1,000 again marked "earlier lines may repeat".
- Ctrl+L (or `clear` and Return) while scrolled up, even a little, now goes to the bottom and shows the cleared screen with the prompt at the top; a program clearing by itself still leaves the view where you are reading.
- Starting Claude Code (or another program that asks the terminal about itself) in a tmux tab no longer prints text such as `^[[?65;4;1;2;6;21;22;17;28c` or `^[P>|SwiftTerm`: tmux answers those questions itself, and Tether no longer types a second, late answer into the pane.
