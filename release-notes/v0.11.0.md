# Tether 0.11.0

Released 2026-11-26

## Highlights

- Copy selected terminal output with its colors and text styles, or copy it as ANSI for a terminal-aware editor.

## New

- Terminal context menus offer **Copy Plain Text**, **Copy with Styles**, and **Copy as ANSI** in live sessions, scrollback, and archived transcripts.
- **Settings ▸ Terminal ▸ Copying** sets the format for ⌘C and copy on selection. Styled copies can include the terminal background.
- ANSI copies keep foreground colors and use visible escape codes by default. Choose **Raw ANSI** for compatible viewers, including the optional Sublime Text preview package.

## Notes

- ⌘C defaults to plain text. Including the terminal background in styled copies is off by default.
- See [Copying terminal output](https://github.com/WhileEndless/tether/blob/v0.11.0/docs/terminal-copying.md) for formats and Sublime Text setup.
