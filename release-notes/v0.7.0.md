# Tether 0.7.0

Released 2026-10-26

## Highlights

- Coding agents waiting for you are noticed: Claude Code asking for plan approval, a question or a permission marks its tab with a raised hand and notifies you, in any tab — nothing to set up in Claude Code.
- Tabs show what is happening: coding agents get their own symbol, a command that is working gets a moving mark, and programs that are only open (vim, less) stay quiet.
- Everything Tether runs for a host can be switched off, for all hosts or for one: monitoring as a whole, each host panel tab, and each background job.

## New

- Settings ▸ Monitoring lists everything Tether runs on hosts with a switch each; every host can choose for itself (System Setting / On / Off) in its editor, from the sidebar's Monitoring menu or the host panel's menu. "What Runs on Hosts" says which switch stops each script.
- The Containers and Kubernetes tabs show only on hosts that have Docker/Podman or kubectl/k3s/microk8s/oc (a setting; a host can still show them).
- Tether understands the Program Status Protocol (OSC 7501) and unwraps tmux passthrough, so programs' notifications reach Tether's tmux tabs too.
- Settings ▸ Terminal ▸ Tabs: agent symbols, a faint dot for idle programs, when a quiet command counts as working. Settings ▸ Terminal ▸ Behavior: notify when an agent waits or is done, and how often agents are looked at.
- Network devices, firewalls and limited shells (Cisco, Junos, FortiOS, RouterOS, PAN-OS, menus, git-shell) are recognised on first contact and get a plain login with their own command line; Tether then runs nothing else on them. Downloads (classic scp) and port forwards still work. Edit Host ▸ Shell, or the host's Monitoring menu, sets it by hand.
- View ▸ Allow Mouse Reporting (⌘R while connected, as in Terminal.app) turns mouse reporting on or off for the terminal in front; while it is not connected, ⌘R still reconnects.
- ⌘E opens the file manager in the current terminal's folder, as its Browse button does (it was ⇧⌘O). Use Selection for Find moves to ⇧⌘E.
- The tab bar's "+" opens a new tab like the one in front (⌘T); hold it for a local terminal, a private tab or a new connection.

## Improved

- The toolbar's New Connection button has its own symbol, and the sidebar's add menu says "Add", so the three buttons are no longer mistaken for one another.
- The Kubernetes tab keeps its header at the top in every state, and messages are aligned to the top and selectable; no host panel tab can move the panel's header to the middle any more.
- Tab numbers (⌘1…⌘9) no longer stay on screen after ⌘ was released in another app or during ⌘Tab.

## Fixed

- The host-key question for a new host was asked twice (monitoring started its own login at the same time); background work now waits for the first login, and the same question from several ssh processes is shown once.
- After `clear`, the prompt could move to the middle of the screen when the window grew (at launch, when a tab was shown, on resize); it stays at the top, and the cleared lines stay in the scrollback.
- Text selected in the history no longer disappears when the command keeps printing: the selection stays unless the program in the terminal tracks the mouse itself.
- Changed ssh settings now reach host monitoring without restarting Tether.
- A host whose shell does not know `exit` (some device CLIs) no longer fails to connect with connection sharing on, and a session that never starts Tether's shell (a menu) no longer waits for ever behind "Connecting".

## Notes

- "Load system information automatically" (Settings ▸ Monitoring) is now the "Monitor the host" switch and really stops monitoring when off; check it if you had switched it off before.
