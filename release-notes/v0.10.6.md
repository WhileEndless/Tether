# Tether 0.10.6

Released 2026-11-15

## Highlights

- Terminals remain responsive while many coding-agent tabs stream in the background.

## New

- Right-click the Archive heading or bottom sidebar icon to clear its list, delete archived transcripts, or clean unlisted recordings.

## Improved

- Restored tabs defer terminal-view setup and replay only a bounded recent tail, so startup prioritizes usable terminals.
- Search starts with open sessions; Full History adds archived and older recordings without draining background-terminal output queues.
- The Archive closes after a short idle period, and close confirmations first show the tab they affect.
- Shared remote-session inventories are reused briefly when several tabs for the same host reconnect together.

## Fixed

- A busy coding-agent terminal no longer raises the redraw rate of other terminals while you type.
- Terminal output coalescing is protected against synchronous re-entry during alternate-screen
  transitions, preventing a stack-overflow crash.
- Resizing a window or moving it between displays avoids repeated scrollback reflows, so active
  terminal input stays responsive during the gesture.

## Notes

- Full-history search includes restored tabs that have not yet created a terminal view.
