# Tether 0.3.1

Released 2026-10-24

## Highlights

- See what runs in a server's tmux sessions without attaching: the command and folder of each window, and for Claude Code, Codex and opencode the name of their session.
- ⌘S saves a whole session to a file you choose.

## New

- Server tmux sessions in the sidebar show what runs in them (full command line and folder) right under their name; the tooltip lists every window.
- Coding agents are recognised: Claude Code, Codex and opencode sessions show their session name (the one you gave them, or the one they generated) and whether Claude Code is working — on server sessions and on open tabs. Names are read from the agents' own files on the server; nothing is installed. Codex and opencode names need `sqlite3` on the server unless you named the Codex thread yourself; otherwise the terminal title is used.
- The Connections inspector lists each window of a tmux session with its command and folder.
- Save Session… (⌘S, File menu): saves everything a session has shown — including older output no longer in memory, read from its recording — as plain text, or as the raw output with colors. The folder and format you chose last are remembered.
- A Refresh button at the bottom of the sidebar reloads the SSH config and the session lists of every connected server.
- Notifications from programs: Claude Code finishing or asking something, a long job's `\e]9;done\a`, the bell in a tab you are not looking at. The tab gets a bell and macOS shows a notification; clicking it brings the tab to the front. OSC 9, OSC 777, OSC 99 and the bell are understood (Settings ▸ Terminal).
- New tabs open next to the current tab instead of at the end (Settings ▸ General ▸ Tabs & Windows can put them at the end).
- ⌘T (and New Session to Same Host) starts the new tab in the folder the current tab's shell is in, like Terminal.app — on this Mac and on servers. Settings ▸ General ▸ Tabs & Windows can start new tabs in the home folder instead.

## Improved

- The list of server sessions refreshes every 15 seconds while a tab to that host is open, so it stays current. Looking at a server's sessions is cheaper: only processes in tmux panes are inspected, several views share one look, and the sidebar is not redrawn when nothing changed.

## Fixed

- Programs in tabs restored after reopening Tether get their terminal back as they left it: mouse reporting, bracketed paste, cursor keys, a hidden cursor and the scroll region were lost. In Claude Code's full-screen mode, wheel scrolling and clicks no longer reached it and pasted text ran line by line.
- Server sessions, coding-agent names and other local information work on this Mac when Tether is started from the Dock: its tools (tmux from Homebrew) were not found there.
- Terminal sizes when Tether is reopened: a restored tab's real size is sent to the server as soon as it is on screen, a size that changes while the tab re-attaches is no longer dropped, and tabs restored in the background no longer resize their programs (which made them redraw twice).
- A saved sudo password sometimes waited for a click instead of asking for Touch ID right away. After one slow answer from tmux, later answers about the terminal were matched to the wrong questions, so Tether could not tell that sudo was waiting.
- Local sessions no longer pick up `$TMUX` when Tether is started from inside tmux: they could be created on that outer tmux server, and ending them could end it.

## Notes

- Known issue: after Tether is reopened, Claude Code's full-screen interface in a restored tab can still be drawn wider than the terminal (tables and the input box run past the right edge). A new tab is not affected. Being looked into.
