# Changelog

## 0.1.1

- Paste images into a terminal: a screenshot copied with ⌃⇧⌘4 (or an image copied from Preview or a browser) is saved as a PNG, uploaded, and its remote path is typed at the prompt. The file manager's *Paste from Mac* accepts copied images too.
- Drop the screenshot thumbnail (and other file promises, such as Photos or Mail attachments) onto a terminal to upload it.
- Copied Finder files paste reliably, even when the clipboard also carries their names as text.
- Latency is shown once, in the host status bar (and in the footer only while that bar is hidden).

- First public release.
